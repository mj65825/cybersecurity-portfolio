## Featured Projects

### [Free AI Chatbot](Projects/AI-Chatbot)

A browser-based AI chatbot built from scratch in Python. It has three switchable bot personalities, conversation memory, streaming replies, a model picker, and save/load for past chats. It runs on Google's free Gemini API tier, or fully offline with a local model through Ollama.

- Python, Gradio, Google Gemini API (`google-genai`), Ollama, python-dotenv
- Backend split into a small provider layer, so switching between cloud and local AI is a one-line config change
- API key kept in a gitignored `.env` file, never in the source code
- Automated pytest suite covering message handling, memory, error handling, and save/load

→ [Source, tests, and full documentation](Projects/AI-Chatbot)
